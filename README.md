# FastAPI Web · 서버 렌더링과 DB 연동 실습

FastAPI·Jinja2·SQLAlchemy·MySQL을 연결한 웹 개발 학습 프로젝트입니다. 선수 목록 조회, 상세 화면, 데이터 수정과 삭제를 통해 HTTP 요청에서 DB 처리·템플릿 응답으로 이어지는 흐름을 연습했습니다.

## 코드와 실행 조건

- [main.py](main.py): 요청 처리, DB 접근, 템플릿 렌더링
- [requirement.txt](requirement.txt): 당시 사용한 패키지 목록

MySQL 데이터베이스와 코드에서 사용하는 선수 테이블을 먼저 준비하고, 소스의 로컬 연결 설정을 자신의 환경에 맞춰야 합니다. 코드가 사용하는 `engine.execute`는 SQLAlchemy 1.x 방식이므로 최신 버전을 무조건 설치하면 호환되지 않습니다.

환경과 템플릿을 준비한 뒤 `python main.py`로 로컬 실행합니다. 이 저장소는 학습 당시의 코드를 보관한 것으로, 재현 환경이 고정된 배포 패키지는 아닙니다.

## 확인할 학습 포인트와 한계

라우팅, 폼 데이터 전달, SQL 실행, HTML 응답을 작은 코드에서 따라갈 수 있습니다. 다만 연결 정보의 소스 내 지정, SQL 문자열 조합, GET 요청을 통한 삭제가 남아 있습니다. 운영용으로 사용하려면 환경변수·파라미터 바인딩·변경 요청 방식과 인증을 수정해야 합니다.
